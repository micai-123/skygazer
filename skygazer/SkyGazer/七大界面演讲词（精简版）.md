## 一、登录注册界面 ⏱️ 1:15

**【核心功能】**
- ✅ 账号注册：手机号 + 验证码，图形验证码防护
- ✅ 登录验证：JWT Token，24 小时有效期
- ✅ 密码找回：BCrypt 加密，安全可靠

**【特色亮点】**
🔐 **三重安全防护**：前端验证 + 后端认证 + 限流防护

**【技术栈】**
Vue 3 | Spring Security | JWT | BCrypt | Redis 限流

> **安全，是我们对用户的第一个承诺。**

---

## 二、个人中心与设置 ⏱️ 1:15

**【核心功能】**
- 👤 个人资料：昵称、头像、手机号
- ⚙️ 偏好设置：默认城市、温度单位、主题风格
- 🔧 系统配置：语言、刷新频率、缓存清理

**【特色亮点】**
🎯 **个性化智能推荐**：根据使用习惯推荐常用城市

**【技术栈】**
Vue 3 Composition API | Pinia | OSS 对象存储 | WebSocket

> **个性化，让每个用户都拥有专属的天气助手。**

---

## 三、实时预览首页大屏 ⏱️ 1:30

**【核心功能】**
- 🌡️ 实时天气：温度、湿度、空气质量
- 📈 24 小时趋势：折线图展示
- 📅 7 天预报：卡片式展示
- 🎯 空气质量：环形图仪表盘
- 📊 生活指数：5 个常用指数速览

**【特色亮点】**
✨ **动态数据可视化**：实时动画 + 交互 + 响应式布局

**【技术栈】**
ECharts 5.5 | CSS3 动画 | GSAP | 虚拟滚动

> **数据，在这里变得生动直观。**

---

## 四、气象地图 ⏱️ 1:15

**【核心功能】**
- 🗺️ 全国热力图：温度分布可视化
- 📚 多层数据叠加：温度、降水、风向、空气质量
- 🔍 区域分析：点击查询详细信息

**【特色亮点】**
🎮 **交互式探索**：缩放、平移、时间轴播放

**【技术栈】**
高德地图 API | ECharts GL | Canvas 分层 | Web Worker

> **地图，让天气数据有了空间维度。**

---

## 五、预警系统界面 ⏱️ 1:15

**【核心功能】**
- 🚨 实时预警：红橙黄蓝四级预警
- 📋 预警详情：发布机构、影响范围、防御指南
- 📜 历史查询：2 年数据保存

**【特色亮点】**
📢 **智能推送**：基于位置的精准推送，多渠道通知

**【技术栈】**
中国气象局 API | WebSocket | 地理围栏 | Redis 缓存

> **预警，是对生命的尊重。**

## 【总结】⏱️ 0:45

**七大界面，一个核心：**

1. 🔐 登录注册 - 安全防护
2. 👤 个人中心 - 个性体验
3. 📊 首页大屏 - 数据可视化
4. 🗺️ 气象地图 - 空间展示

6. 🎯 生活指数 - 多维评估

- 部署：Docker

**设计理念：**
- 以用户为中心

- AI 赋能体验
