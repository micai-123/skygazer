## ⚠️ 重要提示

### 1. Docker Desktop 必须启动
```
错误示例：
failed to connect to the docker API...

解决方案：
启动 Docker Desktop 并等待 Engine running
```

### 2. 首次构建时间较长
- 首次构建需要下载 Docker 镜像
- 预计时间：5-10 分钟
- 请保持网络连接稳定

### 3. 端口占用问题
确保以下端口未被占用：
- 80 (前端)
- 8080 (后端)
- 3306 (MySQL)
- 6379 (Redis)

**检查端口占用**：
```powershell
netstat -ano | findstr :80
netstat -ano | findstr :8080
netstat -ano | findstr :3306
netstat -ano | findstr :6379
```

## 🆘 故障排查

### 问题 1：Docker 未运行
**现象**：执行命令时报错 "failed to connect to the docker API"
**解决**：启动 Docker Desktop

### 问题 2：构建失败
**现象**：Docker 构建过程中报错
**解决**：
1. 检查网络连接
2. 检查后端 JAR 包是否存在
3. 查看详细错误信息

### 问题 3：服务无法启动
**现象**：容器启动后立即退出
**解决**：
1. 查看日志：`docker compose -f docker-compose.prod.yml logs backend`
2. 检查配置是否正确
3. 检查端口是否被占用
