# SkyGazeer 快速开始指南

> ⏱️ 5 分钟快速部署指南

---

## 🚀 方式一：Docker 一键部署（最简单）

### 前置条件
- 已安装 Docker Desktop (Windows/Mac) 或 Docker Engine (Linux)
- 系统内存至少 8GB

### 三步启动

#### 步骤 1：准备配置

```bash
# 复制配置文件
cd config
copy .env.production .env.production.local

# 编辑 .env.production.local，至少修改以下配置：
# - DB_PASSWORD=your_password
# - REDIS_PASSWORD=your_password
# - JWT_SECRET=your_secret_key
```

#### 步骤 2：构建并启动

**Windows 用户**：双击运行 `docker-build.bat`

**或手动执行**：
```bash
# 构建后端
cd backend
mvnw clean package -DskipTests

# 构建并启动 Docker
cd ../docker
docker compose -f docker-compose.prod.yml up -d --build
```

#### 步骤 3：访问应用

打开浏览器访问：**http://localhost**

✅ 完成！

## 📦 方式二：本地部署（适合开发）

### 前置条件
- Java 21+
- Node.js 18+
- Maven 3.8+
- MySQL 8.0+
- Redis 7.0+

### 快速步骤

#### 1. 启动数据库和缓存

```bash
# 使用 Docker 快速启动 MySQL 和 Redis
docker run -d --name mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root mysql:8.0
docker run -d --name redis -p 6379:6379 redis:alpine
```

#### 2. 初始化数据库

```bash
mysql -u root -p < backend/src/main/resources/db/migration/V1__Init_Schema.sql
mysql -u root -p < backend/src/main/resources/db/migration/V2__Add_Vector_Knowledge.sql
```

#### 3. 启动后端

```bash
cd backend
mvnw spring-boot:run
```

#### 4. 启动前端

```bash
cd frontend
npm install
npm run dev
```

#### 5. 访问应用

- 前端开发服务器：http://localhost:3000
- 后端 API：http://localhost:8080

## 🛠️ 方式三：使用打包脚本（推荐新手）

### Windows 用户

1. **双击运行** `build-package.bat`
2. 等待自动完成构建
3. 进入生成的 `SkyGazeer-Package-YYYYMMDD` 文件夹
4. **双击运行** `start.bat`
5. 浏览器自动打开 http://localhost

### 配置文件

在启动前，确保已配置 `config\.env.production.local`：

```bash
# 数据库密码
DB_PASSWORD=your_password

# Redis 密码
REDIS_PASSWORD=your_password

# JWT 密钥（至少 32 位）
JWT_SECRET=your_very_long_secret_key_here

# OpenAI API 密钥（如需 AI 功能）
OPENAI_API_KEY=sk-xxx

# 和风天气 API 密钥
QWEATHER_API_KEY=your_qweather_key
```

## ❓ 常见问题

### Q: Docker 启动失败？
**A**: 
1. 确保 Docker Desktop 正在运行
2. 检查端口是否被占用：`netstat -ano | findstr :80 :8080 :3306 :6379`
3. 查看日志：`docker compose -f docker-compose.prod.yml logs`

### Q: 数据库连接失败？
**A**:
1. 确认 MySQL 容器/服务已启动
2. 检查 `.env.production.local` 中的密码配置
3. 确认数据库已初始化

### Q: 前端页面空白？
**A**:
1. 打开浏览器控制台查看错误
2. 确认后端 API 服务正常
3. 清除浏览器缓存

### Q: 如何停止服务？
**A**:
```bash
# Docker 方式
docker compose -f docker-compose.prod.yml down

# 或运行脚本
docker-stop.bat
```

### Q: 如何查看日志？
**A**:
```bash
# 查看所有服务日志
docker compose -f docker-compose.prod.yml logs -f

# 查看单个服务日志
docker compose -f docker-compose.prod.yml logs backend
docker compose -f docker-compose.prod.yml logs frontend
```
