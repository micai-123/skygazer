# SkyGazer 启动手册（START HERE）

> **⚠️ 下次启动前，务必先阅读本文件。**
> 本项目由 4 部分组成：**MySQL + Redis（基础中间件）→ 后端 Spring Boot → 前端 Vue →（可选）Python 天气模型服务**。
> 建议按下面的顺序启动，避免后端因连不上中间件而报错。

---

## 一、环境与端口速查

| 组件 | 端口 | 作用 | 是否必需 |
|------|------|------|----------|
| MySQL | 3306 | 业务数据库 `skygazer_weather` | 必需 |
| Redis | 6379 | 会话记忆 / 向量库 | 必需 |
| 后端 Spring Boot | 8080（上下文 `/api`） | 业务 + AI 接口 | 必需 |
| 前端 Vue (Vite) | **3000** | 用户界面 | 必需 |
| 模型服务 Flask | 5000 | 天气图片识别（/weather-image） | 可选 |
| DeepSeek API | 443(远程) | AI 对话（Key 已配默认值） | 需联网 |

> 注：前端实际端口为 `vite.config.js` 中配置的 **3000**（不是 README 里写的 5173）。
> 前端通过 Vite 代理将 `/api` 转发到 `http://localhost:8080`，所以浏览器访问 `http://localhost:3000` 即可。

---

## 二、启动顺序

```
① MySQL  ──▶  ② Redis  ──▶  ③ 后端(8080)  ──▶  ④ 前端(3000)  ──▶  (⑤ 模型服务 5000 可选)
```

---

## 三、详细步骤

### ① MySQL（必需）
- 本地需已安装并运行 MySQL 8。
- 连接信息（见 `backend/src/main/resources/application-dev.yml`）：
  - 库名：`skygazer_weather`
  - 账号：`root` / 密码：`YOUR_MYSQL_PASSWORD`
- 首次启动前需建库并执行迁移脚本：
  - 脚本目录：`backend/src/main/resources/db/migration/`
  - 顺序：`V1__Init_Schema.sql` → `V2__Add_Vector_Knowledge.sql`

### ② Redis（必需）
- 推荐 Docker：
  ```powershell
  docker run -d --name redis --restart unless-stopped -p 6379:6379 redis
  ```
- 或本地直接运行 `redis-server`。

### ③ 后端（必需）
直接在**命令提示符 (cmd)** 中执行（Maven 已固定路径）：
```bat
cd /d D:\MyProject\jishe2\skygazer\backend
"D:\JavaSoft\maven\apache-maven-3.6.3\bin\mvn.cmd" -Dmaven.test.skip=true spring-boot:run
```
- 首次运行会下载依赖，稍慢。
- 启动成功标志：`Started WeatherApplication` 且监听 8080。
- 健康检查：`http://localhost:8080/api/health`
- 已有 `backend/scripts/start_backend.bat` 可用，但它把日志重定向到 `D:\MyProject\jishe2\backend_run.out/err`（后台运行、不显示控制台）。

### ④ 前端（必需）
在 **PowerShell** 中执行：
```powershell
cd D:\MyProject\jishe2\skygazer\frontend
npm install        # 仅首次 / 依赖变动时
npm run dev        # 启动后访问 http://localhost:3000 会自动打开浏览器
```
- 若 `npm install` 报平台相关错误，确认 Node.js ≥ 18。

### ⑤ 天气模型服务（可选，仅天气图片识别需要）
在 **PowerShell** 中执行：
```powershell
cd D:\MyProject\jishe2\skygazer\weather-model-api
pip install -r requirements.txt   # 仅首次，需 PyTorch + OpenCV + Flask
python serve_api.py               # 监听 http://0.0.0.0:5000
```
- 依赖模型权重：`weather-model-api/results/model_sample.pth`（缺失会启动失败）。
- 健康检查：`http://localhost:5000/health`
- 后端通过 `WEATHER_MODEL_BASE_URL`（默认 `http://localhost:5000`）调用它。

1. 后端：`curl http://localhost:8080/api/health` → 返回 JSON 健康状态。
2. 前端：浏览器打开 `http://localhost:3000`，页面正常加载、天气数据可显示。

## 五、常见问题

- **后端启动报数据库连接失败**：确认 MySQL 已运行且 `skygazer_weather` 库已建好，账号密码与 `application-dev.yml` 一致。
- **Redis 连接失败**：确认 Redis 已启动（6379）。会话记忆/向量库依赖它。
- **`mvn` 编译测试报错**：已默认加 `-Dmaven.test.skip=true`，如遇其他编译问题再加 `-DskipTests`。
- **前端页面空白 / 接口 404**：确认后端已在 8080 运行，且前端走的是 3000 端口（Vite 代理到 8080）。
- **AI 对话无回复**：DeepSeek API Key 已配默认值，需本机能访问外网 `api.deepseek.com`；RAG 向量检索在本配置下已关闭（DeepSeek 无 embedding 接口），不影响问答与工具调用。
