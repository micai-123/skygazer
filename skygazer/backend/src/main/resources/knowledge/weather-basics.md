# 气象基础知识

天气是指某一地区在某一瞬间或某一短时间内大气状态和大气现象的综合。常见的天气要素包括气温、气压、湿度、风、降水、云、能见度等。气温反映空气的冷热程度，通常用摄氏度表示；气压是单位面积上大气柱的重量，海平面气压平均约为 1013 hPa。

# 天气预报原理

现代天气预报依赖数值天气预报（NWP）模式，通过对大气运动方程组进行数值求解，并结合气象卫星、雷达、地面与探空观测资料进行同化，从而预测未来天气演变。短期预报（1—3 天）准确率较高，而中长期预报的不确定性会显著增大。

# 气象预警信号

气象预警信号一般由低到高分为蓝、黄、橙、红四级，分别对应一般、较重、严重和特别严重。常见类型包括暴雨、暴雪、寒潮、大风、高温、雷电、大雾、台风等。收到高级别预警时，应尽量减少外出，关注官方发布的防御指引，做好人身与财产安全防护。

# 生活气象指数

生活气象指数是将气象条件与人体健康、日常生活相结合的量化参考，常见有穿衣指数、紫外线指数、舒适度指数、洗车指数、运动指数、旅游指数、空气污染扩散条件等。例如紫外线指数较高时应做好防晒；舒适度指数偏低时注意保暖；洗车指数差时不宜洗车。

# 如何解读实况天气

阅读实况天气时应综合多项要素：气温与体感温度可能差异明显，湿度高会让人感觉更闷热，风速与风向影响体感冷暖与污染物扩散。空气质量指数（AQI）用于描述空气受污染程度，数值越低代表空气越洁净；当 AQI 偏高时需减少户外活动并佩戴口罩。
