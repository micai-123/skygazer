# 暴雨与洪涝防御

暴雨指 24 小时内降水量达到 50 毫米以上，按强度分为暴雨、大暴雨和特大暴雨。持续强降水易引发城市内涝、山体滑坡和中小河流洪水。防御要点：关注气象部门发布的暴雨预警，提前清理排水通道；尽量避免前往低洼地带、地下空间与山区；驾车遇积水路段不要贸然通过，水深超过排气管高度即应绕行；家中可准备沙袋、挡水板与应急照明。

# 高温与中暑防护

高温预警通常针对日最高气温达到 35℃ 及以上。长时间高温暴露易引发中暑，严重时可发展为热射病，危及生命。防护建议：尽量避免在 11 时至 16 时高温时段进行户外剧烈活动；外出佩戴遮阳帽、太阳镜，及时补充水分与电解质；室内保持通风或使用空调，但空调温度不宜与外界温差过大；出现头晕、恶心、皮肤干燥发烫等中暑征兆应立即转移至阴凉处并就医。

# 雷电与大风应对

雷电天气应尽量留在室内并远离门窗、金属管道与大型电器；户外时远离孤立高树、广告牌与水域，不要拨打有线电话。大风（阵风 7 级以上）易吹落高空物体，应加固或收回阳台、窗外物品，行人避免在高楼与临时构筑物下停留。台风影响期间应密切关注路径预报，提前储备饮水、食物与电源。

# 寒潮与低温冰冻

寒潮带来急剧降温、大风与雨雪，易引发道路结冰与农作物冻害。应对：及时添衣保暖，重点保护头部、手脚等末梢部位；注意取暖安全，使用煤炉、燃气设备时保持通风，防范一氧化碳中毒；雨雪后出行穿防滑鞋，驾车降低车速、加大车距；农业与畜牧养殖需提前采取保温防冻措施。

# 大雾与霾的健康影响

大雾与霾会降低能见度并抬升颗粒物浓度。能见度低于 200 米时驾驶应开启雾灯、控制车速；空气质量指数（AQI）较高时减少户外锻炼，敏感人群（老人、儿童、呼吸系统疾病患者）宜佩戴口罩并关闭门窗，必要时开启空气净化设备。
