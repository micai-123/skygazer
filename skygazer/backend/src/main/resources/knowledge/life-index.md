# 穿衣指数

穿衣指数根据气温、风、湿度等综合评定，通常分为 1—8 级，级数越小代表越适宜轻薄着装。一般气温在 25℃ 以上可穿短袖，15—25℃ 宜长袖衬衫或薄外套，5—15℃ 需毛衣或夹克，0—5℃ 应穿羽绒服或厚棉衣，0℃ 以下要注意内层排汗、中层保暖、外层防风的三层穿法。湿度高或风力大时体感更冷，应适当加衣。

# 紫外线指数

紫外线指数反映太阳紫外线辐射强度，分为 1—11+ 级。指数 0—2 为低，基本无需防护；3—5 为中等，外出可戴帽；6—7 为高，应使用 SPF30+ 防晒霜并减少正午暴晒；8—10 为很高，11+ 为极高，应尽量待在阴凉处，每两小时补涂防晒，并佩戴墨镜防护眼睛。雪地、水面会反射增强紫外线，户外运动时尤需注意。

# 舒适度与体感温度

人体舒适度指数综合气温、湿度与风速，分 4 级描述冷暖与干湿感受。体感温度常低于实际气温：风速每增加，热量散失加快，体感更冷；高湿度在高温时使闷热感增强，在低温时加剧阴冷。判断穿衣与出行不能只看气温，应结合湿度与风力给出的体感温度。

# 洗车与运动指数

洗感指数依据未来降水概率评定：未来两天无降水时适宜洗车，反之不宜。运动指数综合温湿度、风、空气质量，适宜（1—2 级）可正常户外运动；较适宜（3 级）需注意补水；不适宜（4—5 级）时建议改为室内活动，尤其在高温、严寒、强风或空气污染较重时。

# 旅游与空气污染扩散

旅游指数结合天气舒适度与景观条件给出出行建议。空气污染扩散条件指数描述大气自我净化能力：等级高时污染物易扩散，空气清新；等级低（静稳、逆温）时污染物累积，AQI 易升高，敏感人群应减少户外停留并关注空气质量预报。
