# 短期与中长期预报

短期预报（未来 1—3 天）以数值模式为主、准确率较高，可较好把握降水时段与强弱。中期预报（4—10 天）反映天气趋势，但具体落区与强度不确定性增大。长期与气候预测主要用于趋势参考，不宜作为具体出行安排的唯一依据。读取预报时应同时关注降水概率、量级与时效，而非仅看文字结论。

# 降水概率的含义

降水概率表示在预报时段和区域内出现可测量降水的可能比例，例如 60% 并非"60% 的地区会下雨"，而是"该时段内下雨的可能性为六成"。概率越高越建议备伞；概率中等（30%—50%）时可结合天气云图与临近预报灵活调整行程。

# 气温与昼夜温差

预报气温通常指百叶箱中离地 1.5 米处的空气温度。城市热岛、海拔、下垫面会使实际体感不同。昼夜温差大（如春秋季超过 10℃）时宜采用"洋葱式"分层穿搭，方便随温度增减衣物，老人儿童尤需注意早晚保暖。

# 风力与风向解读

风向指风的来向（如北风即从北吹来），风力按蒲福风级划分，0 级无风、3—4 级体感明显、6 级以上影响出行与高空作业。沿海与山口地带风力常强于内陆，预报大风时应收好易坠物、减少涉水与登山活动。

# 雷达与卫星在临近预报中的作用

天气雷达可监测降水回波的位置、强度与移动，是 0—2 小时临近预报的核心工具；气象卫星提供云系宏观演变。公众可通过雷达拼图判断本地降水何时临近、移向何方，作为短时出行决策的有益补充。
