# 天气系统前端设计参考方案

## 1. 文档概览
**版本：** v1.0 (2026-03-24)
**状态：** 设计初稿
**目标：** 基于“浅蓝色调”视觉规范，构建一个简洁、智能且具备舒缓感的天气应用前端交互界面。

---

## 2. 视觉风格与调性
### 2.1 核心理念
*   **舒缓式界面 (Soothing UI)：** 遵循 2026 年最新趋势，通过极简的视觉噪音和柔和的动画，缓解用户在快速生活中的压力。
*   **呼吸感：** 增加留白（Negative Space），让核心天气数据（如气温）成为视觉焦点。

### 2.2 色彩方案 (Color Palette)
采用动态浅蓝色系为主，并根据实时天气状态进行细微偏移：

| 天气状态 | 主色调 (Hex) | 辅助色/渐变 (Hex) | 视觉感受 |
| :--- | :--- | :--- | :--- |
| **默认/晴朗** | `#E3F2FD` (浅天空蓝) | `#BBDEFB` | 清新、开阔 |
| **多云/阴天** | `#CFD8DC` (蓝灰色) | `#B0BEC5` | 沉静、柔和 |
| **雨雪/潮湿** | `#C5CAE9` (靛蓝紫) | `#9FA8DA` | 清凉、带有水汽感 |
| **深色模式** | `#1A237E` (深靛蓝) | `#0D47A1` | 宁静、深邃 |

---

## 3. 页面布局与功能模块
### 3.1 顶部核心展示区 (Hero Section)
*   **地理位置：** 左上角显示，点击可切换城市（支持手势侧滑）。
*   **数字气温：** 居中超大字体显示，使用带有“呼吸感”的动态字体。
*   **天气描述：** 如“清心晴朗”，位于温度下方。
*   **动态背景：** 浅蓝色背景上辅以微小的粒子动效（如浮动的白云或轻微的雨丝感，不干扰阅读）。

### 3.2 中部交互数据区 (Insight Cards)
*   **24小时预报（横向滚动）：**
    *   卡片式设计，背景采用半透明毛玻璃（Glassmorphism）效果。
    *   关键点：标注未来 2 小时内的降雨突变提醒。
*   **详细指标矩阵：**
    *   湿度、风速（风向玫瑰图）、紫外线指数、PM2.5。
    *   采用极简线性图标。

### 3.3 底部预警与生活建议区 (Contextual Feed)
*   **7天趋势曲线：** 采用贝塞尔曲线展示气温起伏，最高/最低温点平滑连接。
*   **生活建议卡片：** 基于 API 返回的穿衣指数、过敏预警等，以插画形式呈现。

## 4. 技术实现指南 (基于 2026 规范)
### 4.1 动态颜色切换技术 (CSS Next)
使用 CSS 变量动态映射 API 状态，实现无缝切换：
```css
:root {
  --weather-primary: #e3f2fd;
  --transition-speed: 0.6s;
}

[data-weather="clear"] { --weather-primary: #e3f2fd; }
[data-weather="rain"] { --weather-primary: #c5cae9; }

.app-container {
  background: linear-gradient(180deg, var(--weather-primary) 0%, #ffffff 100%);
  transition: background var(--transition-speed) ease-in-out;
}
```

### 4.2 响应式与无障碍 (Accessibility)
*   **对比度：** 核心文字（气温）必须达到 WCAG 2.1 AA 级对比标准（即使在浅色背景下）。
*   **触觉反馈：** 2026 年的主流设计应包含手势震动反馈，如滑动温度曲线时有轻微的触感反馈。

---

## 5. 交互设计细节要求
1.  **下拉刷新：** 刷新图标应设计为气象相关的动效（如旋转的小风车）。
2.  **转场动画：** 切换城市时，云朵元素应有视差滚动（Parallax Scrolling）效果。
3.  **标准化映射：** 前端需建立统一的映射表，确保第三方 API 的“Light Rain”与“Drizzle”能精准对应至预定义的“雨天色系”。

---

## 6. 设计挑战与应对方案
*   **信息载量平衡：** 避免在首页堆砌过多专业气象术语，仅在用户点击具体指标时展开详细分析。
*   **性能考量：** 即使使用 Rust 开发后端或类似高性能框架，前端动画应优先使用 GPU 加速（CSS Transform），确保低端设备也能流畅展示浅蓝色渐变。
