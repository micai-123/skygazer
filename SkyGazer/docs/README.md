# SkyGazer AI 智能气象决策系统

## 项目简介

基于 2026 年最新设计规范构建的智能天气应用前端系统，采用舒缓式界面设计理念，提供沉浸式的气象数据展示体验。

## 技术栈

- **HTML5** - 语义化结构
- **CSS3** - 毛玻璃效果、动态颜色、流畅动画
- **JavaScript ES6+** - 模块化交互逻辑
- **ECharts 5.4** - 数据可视化图表
- **响应式设计** - 支持多种设备尺寸

## 项目结构

```
jishe02/
├── index.html              # 主页面
├── package.json            # 项目配置
├── vite.config.js          # Vite 构建配置
├── server.py               # Python 本地服务器
├── start-server.bat        # Windows 启动脚本
├── public/                 # 静态资源
│   ├── index.html          # 加载页面
│   └── manifest.json       # PWA 配置
└── src/                    # 源代码
    ├── styles/
    │   └── main.css        # 主样式文件
    └── js/
        └── main.js         # 主脚本文件
```

## 快速启动

### 方式一：Python 服务器（推荐）

```bash
# Windows
双击运行 start-server.bat

# 或命令行
python server.py
```

访问地址：http://localhost:8000

### 方式二：Vite 开发服务器（需要 Node.js）

```bash
npm install
npm run dev
```

## 功能特性

### 1. 核心气象展示
- 实时温度显示（带呼吸动画）
- 地理位置 + 空气质量指示
- 风速、湿度等关键指标

### 2. 24小时预报
- 横向滚动时间线
- 高亮当前时段
- 天气图标动态展示

### 3. 区域气象地图
- 模拟雷达扫描效果
- 多图层切换（云图/降水/气压）
- 实时状态更新

### 4. AI 智慧助理
- 自然语言问答
- 天气咨询建议
- 行程规划推荐

### 5. 多模态识图
- 拖拽上传天空照片
- AI 云层分析
- 分钟级天气修正

### 6. 7日趋势图表
- 贝塞尔曲线平滑展示
- 最高/最低气温对比
- 交互式数据提示

### 7. 生活决策建议
- 穿衣指数
- 户外运动建议
- 洗车指数
- 呼吸健康提示

### 8. 用户认证系统 ⭐ 新增
- **智能触发机制**：页面任意点击自动弹出登录提示
- **双重验证**：登录/注册双表单，支持表单切换
- **表单验证**：实时验证用户名、邮箱、密码等输入
- **密码显示切换**：点击图标可显示/隐藏密码
- **记住我功能**：支持 localStorage/sessionStorage 两种存储方式
- **背景虚化**：10px 高斯模糊背景，提升视觉层次感
- **防抖动处理**：1秒内防重复点击，避免异常
- **状态持久化**：登录状态自动保存，刷新页面保持登录
- **自动登录**：检测已登录用户，自动跳过登录流程
- **响应式设计**：完美适配移动端和桌面端
- **无障碍支持**：完整的 ARIA 标签和键盘导航支持

```javascript
// 通过 data-weather 属性切换主题

```
