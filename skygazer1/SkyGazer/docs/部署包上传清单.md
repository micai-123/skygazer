# 📦 SkyGazeer 部署包上传清单

> 根据你的部署场景选择需要上传的文件

---

## 方案一：Docker 部署包（推荐⭐）

### 适用场景
- 服务器部署
- 生产环境
- 需要环境隔离

### 需要上传的文件

**最小化必需文件**：

```
SkyGazer-Docker-Package/
├── docker/
│   ├── docker-compose.prod.yml          ✅ 必须
│   └── 一键启动.bat                      ⭕ 可选（方便启动）
├── backend/
│   └── target/
│       └── weather-backend-1.0.0.jar    ✅ 必须
├── frontend/
│   ├── Dockerfile                       ✅ 必须
│   ├── package.json                     ✅ 必须
│   ├── package-lock.json                ⭕ 可选
│   ├── vite.config.js                   ⭕ 可选
│   ├── nginx.conf                       ✅ 必须
│   └── src/                             ⭕ 可选（Docker 构建需要）
├── config/
│   ├── .env.production                  ✅ 必须（配置模板）
│   └── .env.production.local.example    ✅ 必须（配置示例）
└── README.md                            ✅ 必须（部署说明）
```

**压缩包大小**：约 50-100 MB（包含源代码）  
**上传时间**：取决于网络速度

### 服务器端操作

上传后在服务器上执行：

```bash
# 1. 解压
unzip SkyGazer-Docker-Package.zip
cd SkyGazer-Docker-Package

# 2. 创建配置文件
cd config
cp .env.production .env.production.local
# 编辑 .env.production.local，修改密码等配置

# 3. 启动
cd ../docker
docker compose -f docker-compose.prod.yml up -d --build
```

## 方案三：Windows 安装包

### 适用场景
- 本地演示
- 离线环境
- 非技术人员使用

### 需要制作和上传的文件

**最终产物**：
```
SkyGazeer-Setup-1.0.0.exe                 ✅ 安装包（约 150-200 MB）
```

**制作安装包需要的文件**：

```
SkyGazer-Installer-Source/
├── skygazer-installer.iss                ✅ Inno Setup 脚本
├── backend/
│   └── weather-backend-1.0.0.jar         ✅
├── frontend/
│   └── dist/                             ✅
├── config/
│   └── .env.production.local             ✅
├── tools/
│   ├── jdk-21/                           ✅ Java 运行环境
│   └── nginx/                            ✅ Nginx 服务器
├── start.bat                             ✅
└── uninstall.bat                         ✅
```

**制作步骤**：
1. 安装 Inno Setup：https://jrsoftware.org/isdl.php
2. 打开 `skygazer-installer.iss`
3. 点击"Compile"编译
4. 生成 `SkyGazeer-Setup-1.0.0.exe`

## 🎯 快速决策指南

### 如果你的目标是...

**部署到 Linux 服务器**
→ 选择 **方案一（Docker 包）**
→ 上传 `SkyGazer-Docker-Package.zip`

**部署到 Windows 服务器**
→ 选择 **方案一（Docker 包）** 或 **方案二（独立包）**
→ 推荐 Docker，环境一致性更好

**本地演示/给客户安装**
→ 选择 **方案三（Windows 安装包）**
→ 上传单个 `.exe` 文件

**开发测试**
→ 选择 **方案二（独立包）**
→ 便于调试和修改

## 📋 推荐的 Docker 部署包结构

让我为你创建一个完整的 Docker 部署包结构：

```bash
# 创建部署包目录
mkdir SkyGazer-Docker-Deployment

mkdir SkyGazer-Docker-Deployment\backend\target
mkdir SkyGazer-Docker-Deployment\frontend
mkdir SkyGazer-Docker-Deployment\config

# 复制必要文件

copy docker\一键启动.bat SkyGazer-Docker-Deployment\docker\
copy backend\target\weather-backend-1.0.0.jar SkyGazer-Docker-Deployment\backend\target\
copy frontend\Dockerfile SkyGazer-Docker-Deployment\frontend\
copy frontend\package.json SkyGazer-Docker-Deployment\frontend\
copy frontend\nginx.conf SkyGazer-Docker-Deployment\frontend\
copy config\.env.production SkyGazer-Docker-Deployment\config\
copy config\.env.production.local SkyGazer-Docker-Deployment\config\.env.production.local.example

# 创建部署说明文档
```

## 📄 部署说明文档模板

创建 `README.md` 包含：

```markdown
# SkyGazeer 部署包

## 版本信息
- 版本号：v1.0.0
- 构建日期：2026-04-20
- 后端版本：weather-backend-1.0.0.jar

## 部署方式

### Docker 部署（推荐）

1. 确保 Docker Desktop 已安装并运行
2. 进入 docker 目录
3. 运行一键启动脚本
4. 访问 http://localhost

### 配置说明

编辑 config/.env.production.local：
- DB_PASSWORD: 数据库密码
- JWT_SECRET: JWT 密钥
- OPENAI_API_KEY: AI API 密钥
- QWEATHER_API_KEY: 天气 API 密钥

## 访问地址
- 前端：http://localhost
- 后端 API：http://localhost:8080/api/health
- 数据库：localhost:3306
- Redis：localhost:6379

## 常见问题
详见 Docker 部署操作指南.md
```

## 🔧 自动化打包脚本

我可以帮你创建一个自动打包脚本：

```powershell
# build-deployment-package.ps1

$packageName = "SkyGazer-Docker-Deployment-$(Get-Date -Format 'yyyyMMdd')"
$packageDir = Join-Path $PSScriptRoot $packageName

# 创建目录结构
Write-Host "创建部署包目录..."
New-Item -ItemType Directory -Force -Path (Join-Path $packageDir "docker")
New-Item -ItemType Directory -Force -Path (Join-Path $packageDir "backend\target")
New-Item -ItemType Directory -Force -Path (Join-Path $packageDir "frontend")
New-Item -ItemType Directory -Force -Path (Join-Path $packageDir "config")
New-Item -ItemType Directory -Force -Path (Join-Path $packageDir "docs")

# 复制文件
Write-Host "复制必要文件..."
Copy-Item "docker\docker-compose.prod.yml" (Join-Path $packageDir "docker\")
Copy-Item "docker\一键启动.bat" (Join-Path $packageDir "docker\")
Copy-Item "backend\target\weather-backend-1.0.0.jar" (Join-Path $packageDir "backend\target\")
Copy-Item "frontend\Dockerfile" (Join-Path $packageDir "frontend\")
Copy-Item "frontend\package.json" (Join-Path $packageDir "frontend\")
Copy-Item "frontend\nginx.conf" (Join-Path $packageDir "frontend\")
Copy-Item "config\.env.production" (Join-Path $packageDir "config\")
Copy-Item "config\.env.production.local" (Join-Path $packageDir "config\.env.production.local.example")

# 复制文档
Write-Host "复制文档..."
Copy-Item "Docker 部署操作指南.md" (Join-Path $packageDir "docs\")
Copy-Item "方案一执行总结.md" (Join-Path $packageDir "docs\")

# 创建 README
Write-Host "创建 README..."
@"
# SkyGazeer Docker 部署包

版本：v1.0.0
构建日期：$(Get-Date -Format 'yyyy-MM-dd')

## 快速开始

1. 启动 Docker Desktop
2. 进入 docker 目录
3. 运行 一键启动.bat
4. 访问 http://localhost

## 配置说明

编辑 config/.env.production.local

## 文档

详见 docs/ 目录
"@ | Out-File -FilePath (Join-Path $packageDir "README.md") -Encoding UTF8

# 压缩
Write-Host "创建压缩包..."
Compress-Archive -Path "$packageDir\*" -DestinationPath "$packageName.zip" -Force

Write-Host "部署包创建完成：$packageName.zip" -ForegroundColor Green
```
