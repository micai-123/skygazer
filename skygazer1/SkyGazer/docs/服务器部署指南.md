## 一、服务器环境准备

### 1.1 服务器配置要求

| 配置项 | 最低要求 | 推荐配置 |
|-------|---------|---------|
| 操作系统 | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |
| CPU | 2核 | 4核及以上 |

| 磁盘 | 40GB SSD | 100GB及以上 SSD |
| 带宽 | 3Mbps | 5Mbps及以上 |
| Docker版本 | 24.x+ | 26.x+ |

### 1.2 验证Docker环境

服务器应已预装Docker环境，执行以下命令验证：

```bash
# 查看Docker版本（应显示 26.x.x）
docker --version

# 查看Docker Compose版本
docker compose version

# 查看Docker服务状态（应显示 active (running)）
systemctl status docker
```

**预期输出示例**：
```

Docker Compose version v2.27.0
● docker.service - Docker Application Container Engine
   Loaded: loaded (/lib/systemd/system/docker.service; enabled)
   Active: active (running)
```

## 二、项目上传到服务器

### 2.1 方式一：Git克隆（推荐）

如果项目已托管到Git仓库，直接在服务器克隆：

```bash
# 创建项目目录
sudo mkdir -p /opt/skygazer
cd /opt/skygazer

# 克隆项目（替换为实际仓库地址）
sudo git clone <项目仓库地址> SkyGazer
cd SkyGazer
```

### 2.2 方式二：本地打包上传

#### 步骤1：在本地Windows打包项目

打开PowerShell，执行：

```powershell
# 进入项目父目录
cd d:\jishe

# 打包SkyGazer项目（排除不必要的目录）
tar -czf SkyGazer.tar.gz SkyGazer `
  --exclude="SkyGazer\frontend\node_modules" `
  --exclude="SkyGazer\backend\target" `
  --exclude="SkyGazer\.git"
```

> **说明**：排除 `node_modules` 和 `target` 可以大幅减小压缩包体积，这些文件可以在服务器上重新构建。

#### 步骤2：上传到服务器

```powershell
# 使用scp上传压缩包
scp SkyGazer.tar.gz root@服务器IP:/opt/skygazer/
```

#### 步骤3：在服务器上解压

SSH登录服务器后执行：

```bash
cd /opt/skygazer
tar -xzf SkyGazer.tar.gz
rm SkyGazer.tar.gz  # 解压后可删除压缩包
```

### 2.3 方式三：使用WinSCP图形化工具

1. 下载安装WinSCP：https://winscp.net/eng/download.php
2. 新建会话，选择 **SFTP** 协议，输入服务器IP和端口（默认22）
3. 登录后：
   - **左侧面板**：导航到 `d:\jishe\SkyGazer`
   - **右侧面板**：导航到 `/opt/skygazer/`
4. 右键点击本地文件夹 → **自定义** → 排除以下目录：
   - `frontend\node_modules`
   - `backend\target`
   - `.git`
5. 点击 **上传** 按钮

### 2.4 确认项目结构

```bash
cd /opt/skygazer/SkyGazer
tree -L 2 -I 'node_modules|target'
```

**预期目录结构**：
```
SkyGazer/
├── backend/              # Spring Boot后端
│   ├── src/
│   ├── pom.xml
│   └── Dockerfile
├── frontend/             # Vue 3前端
│   ├── src/
│   ├── package.json
│   ├── nginx.conf
│   └── Dockerfile
├── config/               # 环境配置
│   ├── .env.production
│   └── .env.production.local
├── docker/               # Docker编排文件
│   ├── docker-compose.yml
│   └── docker-compose.prod.yml
└── docs/                 # 项目文档
```

## 三、配置文件设置

### 3.1 创建生产环境配置

```bash
# 进入配置目录
cd /opt/skygazer/SkyGazer/config

# 基于模板创建本地配置
cp .env.production .env.production.local

# 编辑配置文件
vim .env.production.local
```

### 3.2 必须修改的关键配置

打开 `.env.production.local`，修改以下配置项：

```bash
# ==================== 数据库配置 ====================
# 数据库密码（必须修改为强密码）
DB_PASSWORD=你的强密码

# ==================== JWT配置 ====================
# 生成随机密钥：openssl rand -base64 32
JWT_SECRET=你的随机密钥（至少32位）

# ==================== 通义千问API ====================
# 替换为你的实际API密钥
OPENAI_API_KEY=sk-你的实际密钥
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

# ==================== 和风天气API ====================
# 替换为你的实际API密钥
QWEATHER_API_KEY=你的实际密钥
```

### 3.3 生成JWT密钥

在服务器终端执行：

```bash
openssl rand -base64 32
```

将输出结果复制到 `JWT_SECRET` 配置项。

### 3.4 配置权限保护

```bash
# 限制配置文件访问权限（仅root可读）
chmod 600 /opt/skygazer/SkyGazer/config/.env.production.local
```

## 四、构建与启动服务

### 4.1 进入Docker配置目录

```bash
cd /opt/skygazer/SkyGazer/docker
```

### 4.2 启动所有服务

```bash
# 使用生产环境配置启动（首次会自动构建镜像）
sudo docker compose -f docker-compose.prod.yml up -d --build
```

**启动过程说明**：
1. 构建前端Docker镜像（安装依赖 + 编译Vue项目）
2. 构建后端Docker镜像（编译Spring Boot项目）
3. 启动MySQL和Redis容器
4. 启动后端和前端容器
5. 执行数据库迁移脚本（Flyway）

### 4.3 查看启动状态

```bash
# 查看所有容器状态
sudo docker compose -f docker-compose.prod.yml ps

# 查看实时日志（按 Ctrl+C 退出）
sudo docker compose -f docker-compose.prod.yml logs -f

# 单独查看某个服务的日志
sudo docker compose -f docker-compose.prod.yml logs -f backend
sudo docker compose -f docker-compose.prod.yml logs -f frontend
```

### 4.4 等待服务就绪

首次启动需要等待所有服务健康检查通过：

```bash
# 持续监控服务状态（按 Ctrl+C 退出）
watch -n 5 'sudo docker compose -f docker-compose.prod.yml ps'
```

**预期状态**（所有服务显示 `healthy`）：
```
NAME                  STATUS
skygazer-frontend     Up (healthy)
skygazer-backend      Up (healthy)
skygazer-mysql        Up (healthy)
skygazer-redis        Up (healthy)
```

> **提示**：首次启动可能需要 2-5 分钟，请耐心等待。

## 六、日常运维管理

### 6.1 服务管理

```bash
# 停止所有服务
sudo docker compose -f docker-compose.prod.yml down

# 启动所有服务
sudo docker compose -f docker-compose.prod.yml up -d

# 重启所有服务
sudo docker compose -f docker-compose.prod.yml restart

# 重启单个服务
sudo docker compose -f docker-compose.prod.yml restart backend

# 查看服务日志（最近100行）
sudo docker compose -f docker-compose.prod.yml logs --tail=100 backend
```

### 6.2 数据备份

#### 备份MySQL数据库

```bash
# 创建备份目录
sudo mkdir -p /opt/skygazer/backups

# 备份数据库（带时间戳）
sudo docker exec skygazer-mysql mysqldump \
  -u root -p'${DB_PASSWORD}' \
  skygazer_weather > /opt/skygazer/backups/skygazer_$(date +%Y%m%d_%H%M%S).sql
```

#### 备份Redis数据

```bash
# 触发Redis后台保存
sudo docker exec skygazer-redis redis-cli BGSAVE

# 复制数据文件
sudo docker cp skygazer-redis:/data/dump.rdb /opt/skygazer/backups/redis_$(date +%Y%m%d).rdb
```

#### 设置定时备份（可选）

```bash
# 编辑crontab
sudo crontab -e

# 添加每天凌晨2点自动备份
0 2 * * * /opt/skygazer/scripts/backup.sh
```

### 6.3 更新部署

```bash
# 拉取最新代码（如果使用Git）
cd /opt/skygazer/SkyGazer
sudo git pull

# 重新构建并启动
cd docker
sudo docker compose -f docker-compose.prod.yml up -d --build

# 清理旧镜像
sudo docker image prune -f
```

### 6.4 清理资源

```bash
# 清理已停止的容器
sudo docker container prune -f

# 清理未使用的镜像
sudo docker image prune -f

# 清理未使用的数据卷
sudo docker volume prune -f

# 一键清理所有未使用资源
sudo docker system prune -f
```

## 七、故障排查

### 7.1 后端启动失败

```bash
# 查看后端详细日志
sudo docker logs skygazer-backend --tail=200

# 常见问题及解决方案：
```

| 问题现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 数据库连接失败 | MySQL未启动或密码错误 | 检查MySQL状态，核对`.env`配置 |
| Redis连接失败 | Redis未启动 | 检查Redis容器状态 |
| API密钥无效 | 配置错误 | 检查`OPENAI_API_KEY`是否正确 |
| 端口被占用 | 8080端口被其他服务占用 | 修改配置或停止占用服务 |

### 7.2 前端无法访问

```bash
# 查看前端日志
sudo docker logs skygazer-frontend

# 检查Nginx配置是否正确
sudo docker exec skygazer-frontend nginx -t

# 检查80端口是否被占用
sudo netstat -tlnp | grep :80
```

### 7.3 数据库初始化失败

```bash
# 查看MySQL日志
sudo docker logs skygazer-mysql --tail=100

# 手动执行迁移脚本
sudo docker exec -i skygazer-mysql mysql \
  -u root -p skygazer_weather < /opt/skygazer/SkyGazer/backend/src/main/resources/db/migration/V1__Init_Schema.sql
```

### 7.4 容器健康检查失败

```bash
# 查看容器健康检查详情
sudo docker inspect skygazer-backend | grep -A 15 "Health"

# 手动执行健康检查
sudo docker exec skygazer-backend wget \
  --no-verbose --tries=1 --spider http://localhost:8080/api/health
```

### 7.5 查看容器资源占用

```bash
# 查看各容器CPU和内存使用情况
sudo docker stats --no-stream
```

## 八、安全加固

### 8.1 配置防火墙

```bash
# 启用UFW防火墙
sudo ufw enable

# 只开放必要端口
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS（如配置SSL）
sudo ufw allow 22/tcp      # SSH

# 查看防火墙状态
sudo ufw status
```

### 8.2 数据库安全加固

编辑 `docker/docker-compose.prod.yml`，注释掉MySQL的端口映射：

```yaml
services:
  mysql:
    # ports:
    #   - "3306:3306"  # 注释掉，禁止外部直接访问
```

修改后重启服务：
```bash
sudo docker compose -f docker-compose.prod.yml down
sudo docker compose -f docker-compose.prod.yml up -d
```

### 8.3 定期更新系统

```bash
# 更新系统包
sudo apt update && sudo apt upgrade -y

# 更新Docker
sudo apt install docker-ce docker-compose-plugin -y
```

### 8.4 配置文件权限

```bash
# 确保敏感文件权限正确
sudo chmod 600 /opt/skygazer/SkyGazer/config/.env.production.local
sudo chown root:root /opt/skygazer/SkyGazer/config/.env.production.local
```

## 九、性能优化

### 9.1 JVM参数调优

编辑 `backend/Dockerfile`，调整JVM参数：

```dockerfile
# 根据服务器内存调整（示例：4GB内存服务器）
ENV JAVA_OPTS="-Xms1g -Xmx2g -XX:+UseG1GC -XX:MaxGCPauseMillis=200"
```

### 9.2 Nginx优化

编辑 `frontend/nginx.conf`：

```nginx
worker_processes auto;

events {
    worker_connections 2048;
    use epoll;
}

http {
    # 启用gzip压缩
    gzip on;
    gzip_types text/plain application/json application/javascript text/css;
    
    # 设置缓存
    location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

### 9.3 MySQL优化

在 `docker-compose.prod.yml` 的MySQL服务中添加：

```yaml
mysql:
  command: >
    --character-set-server=utf8mb4
    --collation-server=utf8mb4_unicode_ci
    --innodb-buffer-pool-size=1G
    --max-connections=200
    --slow-query-log=1
    --long-query-time=2
```

### 9.4 Redis优化

在 `docker-compose.prod.yml` 的Redis服务中添加：

```yaml
redis:
  command: >
    --maxmemory 512mb
    --maxmemory-policy allkeys-lru
    --appendonly yes
```
