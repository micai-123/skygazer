## 1. 系统概述

### 1.1 系统简介

智观天象 AI 是一个基于人工智能的智能气象决策系统，为用户提供实时天气预报、气象地图、智能分析和生活指数等功能。系统采用前后端分离架构，前端基于原生 JavaScript 开发，后端需提供 RESTful API 接口。

### 1.2 技术栈

**前端技术**:
- HTML5 + CSS3 + JavaScript (ES6+)
- ECharts (数据可视化)
- LocalStorage/SessionStorage (本地存储)
- Fetch API (数据请求)

**后端要求**:
- RESTful API 架构
- JSON 数据格式
- JWT Token 认证
- CORS 跨域支持

### 1.3 页面结构

| 页面 | 文件名 | 功能描述 |
|------|--------|----------|
| 首页 | index.html | 实时天气预览、用户登录注册 |
| 气象地图 | map.html | 气象数据可视化地图 |
| 智能分析 | analysis.html | 天气趋势分析与预测 |
| 生活指数 | lifestyle.html | 生活建议与指数展示 |

## 2. 功能模块详细说明

### 2.1 用户认证模块

#### 2.1.1 功能描述

用户登录、注册、自动登录、记住密码等功能。

#### 2.1.2 前端实现

**登录功能**:
- 用户名/邮箱 + 密码登录
- 记住密码功能（7天免登录）
- 表单验证（用户名非空、密码长度≥6）
- 登录状态持久化

**注册功能**:
- 用户名 + 邮箱 + 密码注册
- 表单验证（用户名≥3位、邮箱格式、密码≥8位、确认密码一致）
- 注册成功自动登录

**自动登录**:
- 检查 LocalStorage/SessionStorage 中的登录状态
- 自动恢复用户会话

#### 2.1.3 数据存储

```javascript
// 登录状态存储
localStorage.setItem('auth_user', JSON.stringify({
    username: '用户名',
    logged_in: true,
    timestamp: 1698765432000
}));

// 用户信息存储
localStorage.setItem('auth_users', JSON.stringify([
    {
        username: '用户名',
        email: 'user@example.com',
        password: '加密密码'
    }
]));
```

### 2.6 主题切换模块

#### 2.6.1 功能描述

支持浅色、深色、自动三种主题模式切换。

#### 2.6.2 主题类型

| 主题标识 | 描述 | 切换规则 |
|----------|------|----------|
| light | 浅色模式 | 明亮背景 + 深色文字 |
| dark | 深色模式 | 深色背景 + 浅色文字 |
| auto | 自动模式 | 根据时间/天气自动切换 |

#### 2.6.3 自动模式规则

```javascript
// 自动主题判断逻辑
function checkAutoTheme() {
    const hour = new Date().getHours();
    const isNight = hour >= 18 || hour < 6;
    const weather = weatherData.current.description;
    
    if (isNight) {
        return 'dark';  // 夜间使用深色模式
    } else if (weather.includes('晴')) {
        return 'light'; // 晴天使用浅色模式
    } else {
        return 'light'; // 默认浅色模式
    }
}
```

#### 2.6.4 数据存储

```javascript
// 主题偏好存储
localStorage.setItem('theme', 'dark');
```

## 6. 业务逻辑规则

### 6.1 用户认证规则

#### 6.1.1 用户名规则

- 长度：3-20字符
- 允许字符：字母、数字、下划线
- 不允许：纯数字、特殊字符、空格
- 唯一性：全局唯一

#### 6.1.2 密码规则

- 最小长度：8字符
- 强度要求：至少包含大小写字母和数字
- 加密方式：bcrypt（cost factor: 10）
- 不允许：常见弱密码

#### 6.1.3 邮箱规则

- 格式验证：标准邮箱格式
- 唯一性：全局唯一
- 验证流程：注册后发送验证邮件

#### 6.1.4 Token 规则

- 类型：JWT (JSON Web Token)
- 有效期：
  - 普通登录：24小时
  - 记住密码：7天
- 刷新机制：过期前1小时可刷新
- 存储位置：前端 LocalStorage/SessionStorage

---

### 6.2 天气数据规则

#### 6.2.1 数据更新频率

| 数据类型 | 更新频率 | 缓存时间 |
|----------|----------|----------|
| 当前天气 | 10分钟 | 5分钟 |
| 逐小时预报 | 1小时 | 30分钟 |
| 7日预报 | 3小时 | 1小时 |
| 生活指数 | 6小时 | 3小时 |
| 地图数据 | 30分钟 | 15分钟 |

#### 6.2.2 数据验证规则

**温度**:
- 范围：-50°C 到 60°C
- 精度：小数点后1位

**湿度**:
- 范围：0% 到 100%
- 精度：整数

**风速**:
- 范围：0 到 200 km/h
- 精度：整数

**空气质量指数**:
- 范围：0 到 500
- 等级划分：
  - 0-50: 优
  - 51-100: 良
  - 101-150: 轻度污染
  - 151-200: 中度污染
  - 201-300: 重度污染
  - >300: 严重污染

#### 6.2.3 地理位置规则

- 坐标系统：WGS84
- 纬度范围：-90 到 90
- 经度范围：-180 到 180
- 精度：小数点后6位

#### 6.3.1 消息限制

- 单条消息长度：最大500字符
- 图片大小：最大5MB
- 图片格式：JPEG, PNG, GIF
- 对话历史：保留最近100条

#### 6.3.2 上下文管理

- 上下文窗口：最近10条消息

- 上下文内容：位置、天气、用户偏好

#### 6.3.3 响应生成

### 7.3 前端异常处理

#### 7.3.1 网络错误

```javascript
try {
    const response = await fetch(url, options);
    
    if (!response.ok) {
        throw new Error(`HTTP ${response.status}: ${response.statusText}`);
    }
    
    const data = await response.json();
    
    if (!data.success) {
        throw new Error(data.message);
    }
    
    return data;
} catch (error) {
    if (error.name === 'TypeError' && error.message.includes('fetch')) {
        // 网络连接错误
        showError('网络连接失败，请检查网络设置');
    } else if (error.message.includes('401')) {
        // 未授权，跳转登录
        redirectToLogin();
    } else {
        // 其他错误
        showError(error.message);
    }
}
```

#### 7.3.2 Token 过期处理

```javascript
// Token过期自动刷新
async function refreshToken() {
    try {
        const response = await fetch('/api/auth/refresh', {
            method: 'POST',
            headers: {
                'Authorization': `Bearer ${getStoredToken()}`
            }
        });
        
        const data = await response.json();
        
        if (data.success) {
            saveToken(data.data.token);
            return data.data.token;
        } else {
            // 刷新失败，跳转登录
            redirectToLogin();
        }
    } catch (error) {
        redirectToLogin();
    }
}
```

### 7.4 后端异常处理建议

#### 7.4.1 全局异常捕获

```javascript
// Express.js 示例
app.use((err, req, res, next) => {
    console.error('Error:', err);
    
    // 验证错误
    if (err.name === 'ValidationError') {
        return res.status(400).json({
            success: false,
            code: 400,
            message: '数据验证失败',
            error: {
                type: err.name,
                field: err.field,
                message: err.message
            }
        });
    }
    
    // 认证错误
    if (err.name === 'UnauthorizedError') {
        return res.status(401).json({
            success: false,
            code: 401,
            message: '未授权访问',
            error: {
                type: 'AuthenticationError',
                message: 'Token无效或已过期'
            }
        });
    }
    
    // 数据库错误
    if (err.code === 'ER_DUP_ENTRY') {
        return res.status(409).json({
            success: false,
            code: 409,
            message: '资源已存在',
            error: {
                type: 'DuplicateError',
                message: '该资源已存在，请勿重复创建'
            }
        });
    }
    
    // 服务器错误
    res.status(500).json({
        success: false,
        code: 500,
        message: '服务器内部错误',
        error: {
            type: 'InternalServerError',
            message: process.env.NODE_ENV === 'production' 
                ? '服务器错误，请稍后重试' 
                : err.message
        }
    });
});
```

const bcrypt = require('bcrypt');

// 密码加密
async function hashPassword(password) {
    const salt = await bcrypt.genSalt(10);

}

async function verifyPassword(password, hashedPassword) {

    if (sanitized.password) {

    }
    
    // 脱敏邮箱
