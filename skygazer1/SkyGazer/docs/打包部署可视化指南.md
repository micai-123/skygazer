## 🔄 Docker 部署完整流程

```
┌─────────────────────────────────────────────────────────────┐
│                    Docker 部署流程                          │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 步骤 1: 准备配置文件                                         │
│ - cd config                                                  │
│ - copy .env.production .env.production.local                │
│ - 编辑配置（数据库密码、API 密钥等）                          │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 步骤 2: 构建后端 JAR 包                                      │
│ - cd backend                                                 │
│ - mvnw clean package -DskipTests                            │
│ - 输出：target/weather-backend-1.0.0.jar                    │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 步骤 3: 构建前端静态资源                                     │
│ - cd frontend                                                │
│ - npm install                                                │
│ - npm run build                                              │
│ - 输出：dist/                                                │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 步骤 4: 构建 Docker 镜像                                     │
│ - cd docker                                                  │
│ - docker compose -f docker-compose.prod.yml build           │
│ - 构建 4 个镜像：                                             │
│   • skygazer-backend                                         │
│   • skygazer-frontend                                        │
│   • mysql:8.0                                                │
│   • redis:alpine                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 步骤 5: 启动服务                                             │
│ - docker compose -f docker-compose.prod.yml up -d           │
│ - 等待健康检查通过（约 2-5 分钟）                               │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 步骤 6: 验证部署                                             │
│ - docker compose -f docker-compose.prod.yml ps              │
│ - 访问 http://localhost                                     │
│ - 测试 API: http://localhost:8080/api/health                │
└─────────────────────────────────────────────────────────────┘
```

## ⚙️ 配置检查清单

### 必须配置项

```bash
# ✅ 数据库配置
DB_USERNAME=root
DB_PASSWORD=your_secure_password    # 必须修改

# ✅ Redis 配置
REDIS_PASSWORD=your_redis_password  # 必须修改

# ✅ JWT 配置
JWT_SECRET=your_32char_secret       # 必须修改，至少 32 位

# ✅ API 密钥（按需）
OPENAI_API_KEY=sk-xxx               # AI 功能需要
QWEATHER_API_KEY=your_key           # 天气数据需要
```

### 可选配置项

```bash
# 服务端口
SERVER_PORT=8080
NGINX_PORT=80

# 日志级别
LOGGING_LEVEL=INFO

# JVM 参数
JAVA_OPTS=-Xms512m -Xmx1024m
```

## 🎯 部署验证清单

### Docker 部署验证

```bash
# 1. 检查容器状态
docker compose -f docker-compose.prod.yml ps
# ✅ 所有容器状态应为 "Up (healthy)"

# 2. 查看日志
docker compose -f docker-compose.prod.yml logs -f
# ✅ 无 ERROR 级别错误

# 3. 测试前端
curl http://localhost
# ✅ 返回 HTML 内容

# 4. 测试后端
curl http://localhost:8080/api/health
# ✅ 返回 {"status":"UP",...}

# 5. 测试数据库连接
docker exec skygazer-mysql mysql -u root -p -e "SHOW DATABASES;"
# ✅ 显示 skygazer_weather 数据库

# 6. 测试 Redis 连接
docker exec skygazer-redis redis-cli ping
# ✅ 返回 PONG
```

### 独立部署验证

```bash
# 1. 检查 Java 进程
jps -l
# ✅ 应看到 weather-backend-1.0.0.jar

# 2. 检查端口监听
netstat -ano | findstr :8080
netstat -ano | findstr :3000
# ✅ 端口应处于 LISTENING 状态

# 3. 测试 API
curl http://localhost:8080/api/health
# ✅ 返回健康状态

# 4. 检查日志文件
tail -f logs/backend.log
# ✅ 查看运行日志
```

## 🔧 故障排查流程图

```
服务启动失败
    │
    ├─→ 检查日志
    │     │
    │     ├─→ 数据库连接失败
    │     │     ├─→ 检查 MySQL 是否启动
    │     │     ├─→ 检查密码配置
    │     │     └─→ 检查数据库是否创建
    │     │
    │     ├─→ Redis 连接失败
    │     │     ├─→ 检查 Redis 是否启动
    │     │     └─→ 检查密码配置
    │     │
    │     ├─→ 端口被占用
    │     │     ├─→ netstat 查看端口占用
    │     │     └─→ 修改配置或停止占用进程
    │     │
    │     └─→ API 密钥无效
    │           └─→ 检查.env 配置
    │
    └─→ 资源不足
          ├─→ 检查内存使用
          └─→ 增加 Docker 资源限制
```

## 📊 性能优化建议

### 生产环境配置

```yaml
# application-prod.yml
spring:
  datasource:
    hikari:
      maximum-pool-size: 20      # 连接池大小
      minimum-idle: 5            # 最小空闲连接
      connection-timeout: 30000  # 连接超时

server:
  tomcat:
    threads:
      max: 200                   # 最大线程数
      min-spare: 10              # 最小空闲线程

logging:
  level:
    root: WARN                   # 生产环境降低日志级别
    com.skygazer: INFO
```

### Docker 资源限制

```yaml
# docker-compose.prod.yml
services:
  backend:
    deploy:
      resources:
        limits:
          cpus: '2.0'            # CPU 限制
          memory: 2G             # 内存限制
        reservations:
          memory: 1G
```

## 🎓 最佳实践

### 1. 版本管理

```bash
# 使用语义化版本号
backend/pom.xml: <version>1.0.0</version>
frontend/package.json: "version": "1.0.0"

# 打标签
git tag -a v1.0.0 -m "Release v1.0.0"
git push origin v1.0.0
```

### 2. 备份策略

```bash
# 数据库备份
docker exec skygazer-mysql mysqldump -u root -p skygazer_weather > backup.sql

# 定期备份（crontab）
0 2 * * * /path/to/backup.sh
```

### 3. 更新流程

```bash
# 1. 备份数据
# 2. 拉取新代码
git pull origin main

# 3. 重新构建
docker compose -f docker-compose.prod.yml up -d --build

# 4. 验证服务
# 5. 清理旧镜像
docker image prune -f
```
