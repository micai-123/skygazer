# SkyGazeer 打包部署指南

> **项目版本**: v1.0.0  
> **文档更新日期**: 2026-04-20  
> **适用环境**: Windows / Linux / macOS

---

## 📦 打包方案概览

SkyGazeer 提供以下三种打包方式：

| 方案 | 适用场景 | 优点 | 难度 |
|------|---------|------|------|
| **方案一：Docker 容器化部署** | 生产环境、服务器部署 | 一键部署、环境隔离、易于扩展 | ⭐⭐ |
| **方案二：前后端独立打包** | 开发测试、自定义部署 | 灵活配置、便于调试 | ⭐⭐⭐ |
| **方案三：Windows 安装包** | 本地演示、离线环境 | 双击安装、用户友好 | ⭐⭐⭐⭐ |

## 方案一：Docker 容器化部署（推荐）⭐

### 1.1 前置要求

- Docker Desktop 26.x+ (Windows/macOS) 或 Docker Engine 26.x+ (Linux)
- Docker Compose Plugin
- 至少 8GB 可用内存
- 至少 20GB 可用磁盘空间

### 1.2 构建步骤

#### 步骤 1：准备环境配置文件

```bash
# 进入配置目录
cd config

# 复制生产环境配置模板
cp .env.production .env.production.local

# 编辑配置文件，填入必要的 API 密钥
# Windows 可使用记事本或 VS Code 打开
notepad .env.production.local
```

**必须配置的关键变量**：
```bash
# 数据库配置
DB_USERNAME=root
DB_PASSWORD=your_secure_password

# Redis 配置
REDIS_PASSWORD=your_redis_password

# AI 服务配置
OPENAI_API_KEY=your_openai_key
OPENAI_BASE_URL=https://api.openai.com/v1

# 和风天气 API 配置
QWEATHER_API_KEY=your_qweather_key
QWEATHER_BASE_URL=https://devapi.qweather.com/v7
QWEATHER_GEO_URL=https://geoapi.qweather.com/v2

# JWT 密钥（建议使用随机生成的 32 位以上字符串）
JWT_SECRET=your_jwt_secret_key
```

#### 步骤 2：构建后端 JAR 包

```bash
# 进入后端项目目录
cd backend

# 使用 Maven 构建（需要安装 Maven 3.8+）
mvn clean package -DskipTests

# 或使用 Maven Wrapper（推荐）
./mvnw clean package -DskipTests

# 构建完成后，target 目录会生成 weather-backend-1.0.0.jar
```

**Windows PowerShell 快速构建命令**：
```powershell
cd backend
.\mvnw clean package -DskipTests
```

#### 步骤 3：构建前端静态资源

```bash
# 进入前端项目目录
cd frontend

# 安装依赖（首次需要）
npm install

# 构建生产版本
npm run build

# 构建完成后，dist 目录会生成静态文件
```

#### 步骤 4：构建 Docker 镜像并启动

```bash
# 进入 docker 目录
cd docker

# 构建并启动所有服务
docker compose -f docker-compose.prod.yml up -d --build

# 查看构建日志
docker compose -f docker-compose.prod.yml logs -f
```

#### 步骤 5：验证部署

```bash
# 查看所有容器状态
docker compose -f docker-compose.prod.yml ps

# 预期输出：
# NAME                  STATUS
# skygazer-frontend     Up (healthy)
# skygazer-backend      Up (healthy)
# skygazer-mysql        Up (healthy)
# skygazer-redis        Up (healthy)
```

**访问应用**：
- 前端：http://localhost
- 后端 API：http://localhost:8080/api/health
- 数据库：localhost:3306 (如需外部访问)

### 1.3 打包成可分发镜像

```bash
# 导出 Docker 镜像为 tar 文件（用于离线环境）
docker save skygazer-frontend:latest skygazer-backend:latest -o skygazer-images.tar

# 压缩镜像文件
7z a skygazer-docker-package.zip skygazer-images.tar docker/docker-compose.prod.yml config/.env.production
```

### 1.4 常用运维命令

```bash
# 查看实时日志
docker compose -f docker-compose.prod.yml logs -f

# 重启某个服务
docker compose -f docker-compose.prod.yml restart backend

# 停止所有服务
docker compose -f docker-compose.prod.yml down

# 停止并删除数据卷（谨慎使用）
docker compose -f docker-compose.prod.yml down -v

# 查看资源占用
docker stats
```

## 方案二：前后端独立打包

### 2.1 后端打包（Spring Boot 可执行 JAR）

#### 构建步骤

```bash
cd backend

# 清理并构建
mvn clean package -DskipTests

# 构建产物位置：
# backend/target/weather-backend-1.0.0.jar
```

#### 创建启动脚本

**Windows 启动脚本** (`start-backend.bat`)：
```batch
@echo off
echo Starting SkyGazeer Backend...
set JAVA_OPTS=-Xms512m -Xmx1024m -XX:+UseG1GC
set SPRING_PROFILES_ACTIVE=prod
java %JAVA_OPTS% -jar target/weather-backend-1.0.0.jar
pause
```

**Linux/macOS 启动脚本** (`start-backend.sh`)：
```bash
#!/bin/bash
echo "Starting SkyGazeer Backend..."
export JAVA_OPTS="-Xms512m -Xmx1024m -XX:+UseG1GC"
export SPRING_PROFILES_ACTIVE=prod
java $JAVA_OPTS -jar target/weather-backend-1.0.0.jar
```

#### 后端配置文件

创建 `backend/src/main/resources/application-prod.yml`：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/skygazer_weather?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
    driver-class-name: com.mysql.cj.jdbc.Driver
  
  data:
    redis:
      host: localhost
      port: 6379
      password: ${REDIS_PASSWORD}
      database: 0

server:
  port: 8080

logging:
  level:
    root: INFO
    com.skygazer.weather: DEBUG
  file:
    name: logs/backend.log
```

### 2.2 前端打包（Vite 静态资源）

#### 构建步骤

```bash
cd frontend

# 安装依赖
npm install

# 构建生产版本
npm run build

# 构建产物位置：
# frontend/dist/
```

#### 配置 Nginx 服务器

创建 `frontend/nginx.conf`：
```nginx
worker_processes auto;
error_log /var/log/nginx/error.log warn;
pid /var/run/nginx.pid;

events {
    worker_connections 1024;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;
    
    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent" "$http_x_forwarded_for"';
    
    access_log /var/log/nginx/access.log main;
    
    sendfile on;
    keepalive_timeout 65;
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
    
    server {
        listen 80;
        server_name localhost;
        root /usr/share/nginx/html;
        index index.html;
        
        # 前端静态文件
        location / {
            try_files $uri $uri/ /index.html;
        }
        
        # 后端 API 代理
        location /api/ {
            proxy_pass http://localhost:8080;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }
        
        # 缓存静态资源
        location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }
}
```

#### 前端启动方式

**使用 Nginx Docker**：
```bash
docker run -d \
  --name skygazer-frontend \
  -p 80:80 \
  -v $(pwd)/dist:/usr/share/nginx/html:ro \
  -v $(pwd)/nginx.conf:/etc/nginx/nginx.conf:ro \
  nginx:alpine
```

**或使用 Node.js 内置服务器**：
```bash
cd frontend
npm run preview -- --port 80 --host
```

### 2.3 数据库初始化

#### MySQL 安装与配置

**Windows 安装**：
1. 下载 MySQL Installer: https://dev.mysql.com/downloads/installer/
2. 选择"Developer Default"安装
3. 设置 root 密码
4. 配置为 Windows 服务

**Linux 安装**：
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install mysql-server-8.0

# CentOS/RHEL
sudo yum install mysql-server
```

#### 创建数据库

```sql
-- 登录 MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE IF NOT EXISTS skygazer_weather 
  CHARACTER SET utf8mb4 
  COLLATE utf8mb4_unicode_ci;

-- 创建用户（可选）
CREATE USER 'skygazer'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON skygazer_weather.* TO 'skygazer'@'localhost';
FLUSH PRIVILEGES;

-- 使用数据库
USE skygazer_weather;

-- 执行迁移脚本
source backend/src/main/resources/db/migration/V1__Init_Schema.sql
source backend/src/main/resources/db/migration/V2__Add_Vector_Knowledge.sql
```

### 2.4 Redis 安装与配置

**Windows 安装**：
- 下载：https://github.com/microsoftarchive/redis/releases
- 或使用 Docker：`docker run -d -p 6379:6379 --name redis redis:alpine`

**Linux 安装**：
```bash
sudo apt install redis-server
sudo systemctl start redis
sudo systemctl enable redis
```

**配置密码**：
```bash
# 编辑 Redis 配置
sudo nano /etc/redis/redis.conf

# 找到并修改：
requirepass your_redis_password

# 重启 Redis
sudo systemctl restart redis
```

## 方案三：Windows 安装包制作

### 3.1 使用 Inno Setup 制作安装包

#### 步骤 1：安装 Inno Setup

下载并安装：https://jrsoftware.org/isdl.php

#### 步骤 2：创建安装包脚本

创建 `skygazer-installer.iss`：
```iss
#define MyAppName "SkyGazeer 智观天象"
#define MyAppVersion "1.0.0"
#define MyAppPublisher "SkyGazer Team"
#define MyAppExeName "SkyGazeer.exe"

[Setup]
AppId={{YOUR-APP-ID}
AppName={#MyAppName}
AppVersion={#MyAppVersion}
AppPublisher={#MyAppPublisher}
DefaultDirName={autopf}\{#MyAppName}
DefaultGroupName={#MyAppName}
AllowNoIcons=yes
LicenseFile=..\docs\LICENSE
OutputDir=installer-output
OutputBaseFilename=SkyGazeer-Setup-{#MyAppVersion}
SetupIconFile=..\frontend\public\favicon.ico
Compression=lzma
SolidCompression=yes
WizardStyle=modern

[Languages]
Name: "chinesesimplified"; MessagesFile: "compiler:Languages\ChineseSimplified.isl"

[Tasks]
Name: "desktopicon"; Description: "{cm:CreateDesktopIcon}"; GroupDescription: "{cm:AdditionalIcons}"; Flags: unchecked
Name: "quicklaunchicon"; Description: "{cm:CreateQuickLaunchIcon}"; GroupDescription: "{cm:AdditionalIcons}"; Flags: unchecked; OnlyBelowVersion: 6.1; Check: not IsAdminInstallMode

[Files]
Source: "..\backend\target\weather-backend-1.0.0.jar"; DestDir: "{app}\backend"; Flags: ignoreversion
Source: "..\frontend\dist\*"; DestDir: "{app}\frontend"; Flags: recursesubdirs createallsubdirs ignoreversion
Source: "..\config\.env.production.local"; DestDir: "{app}\config"; Flags: ignoreversion
Source: "start.bat"; DestDir: "{app}"; Flags: ignoreversion
Source: "nginx.exe"; DestDir: "{app}"; Flags: ignoreversion
; 添加其他必要文件

[Icons]
Name: "{group}\{#MyAppName}"; Filename: "{app}\{#MyAppExeName}"
Name: "{autodesktop}\{#MyAppName}"; Filename: "{app}\{#MyAppExeName}"; Tasks: desktopicon
Name: "{userappdata}\QuickLaunch\{#MyAppName}"; Filename: "{app}\{#MyAppExeName}"; Tasks: quicklaunchicon

[Run]
Filename: "{app}\start.bat"; Description: "{cm:LaunchProgram,{#StringChange(MyAppName, '&', '&&')}}"; Flags: nowait postinstall skipifsilent
```

#### 步骤 3：创建启动器

创建 `start.bat`：
```batch
@echo off
start "" "java" -jar "backend\weather-backend-1.0.0.jar"
timeout /t 5 /nobreak
start "" "nginx.exe" -p "frontend"
start http://localhost
```

#### 步骤 4：编译安装包

1. 打开 Inno Setup Compiler
2. 加载 `skygazer-installer.iss`
3. 点击"Compile"
4. 安装包将生成在 `installer-output` 目录

### 3.2 使用 Electron 制作跨平台桌面应用

#### 步骤 1：安装 Electron

```bash
cd frontend
npm install --save-dev electron electron-builder
```

#### 步骤 2：创建 Electron 主进程文件

创建 `frontend/electron/main.js`：
```javascript
const { app, BrowserWindow, Menu } = require('electron')
const path = require('path')
const { spawn } = require('child_process')

let mainWindow
let backendProcess

function createWindow() {
  mainWindow = new BrowserWindow({
    width: 1400,
    height: 900,
    webPreferences: {
      nodeIntegration: true,
      contextIsolation: false
    },
    icon: path.join(__dirname, 'public/favicon.ico')
  })

  mainWindow.loadFile('dist/index.html')
  
  // 启动后端
  backendProcess = spawn('java', ['-jar', '../backend/target/weather-backend-1.0.0.jar'], {
    cwd: __dirname,
    stdio: 'ignore'
  })

  mainWindow.on('closed', () => {
    if (backendProcess) {
      backendProcess.kill()
    }
    mainWindow = null
  })
}

app.whenReady().then(createWindow)

app.on('window-all-closed', () => {
  if (backendProcess) {
    backendProcess.kill()
  }
  app.quit()
})
```

#### 步骤 3：配置 electron-builder

在 `package.json` 中添加：
```json
{
  "build": {
    "appId": "com.skygazer.weather",
    "productName": "SkyGazeer 智观天象",
    "version": "1.0.0",
    "directories": {
      "output": "release"
    },
    "files": [
      "dist/**/*",
      "electron/**/*",
      "package.json"
    ],
    "win": {
      "target": "nsis",
      "icon": "public/favicon.ico"
    },
    "mac": {
      "target": "dmg"
    },
    "linux": {
      "target": "AppImage"
    }
  }
}
```

#### 步骤 4：构建安装包

```bash
npm run electron:build
```

## 常见问题 FAQ

### Q1: Docker 构建失败怎么办？
**A**: 检查以下几点：
1. Docker Desktop 是否正常运行
2. 内存是否充足（建议分配 4GB 以上）
3. 网络是否能访问 Docker Hub
4. 使用国内镜像源加速

### Q2: 后端启动时数据库连接失败？
**A**: 
1. 确认 MySQL 容器/服务已启动
2. 检查 `.env.production.local` 中的数据库密码
3. 确认数据库已正确初始化

### Q3: 前端页面空白或报错？
**A**:
1. 检查浏览器控制台错误信息
2. 确认后端 API 服务正常
3. 检查 Nginx 配置是否正确
4. 清除浏览器缓存后重试

### Q4: 如何修改默认端口？
**A**:
- 前端：修改 `nginx.conf` 中的 `listen` 端口
- 后端：修改 `application-prod.yml` 中的 `server.port`
- 更新 `docker-compose.prod.yml` 中的端口映射
