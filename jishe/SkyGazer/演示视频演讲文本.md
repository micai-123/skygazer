## 【产品介绍】1:00 - 2:00（60 秒）

### 画面：系统架构动画 + 核心功能展示

**演讲词**：

> SkyGazeer 是一个**基于 Spring AI 的多模态智能天气预测与决策系统**。
>
> **技术架构上**，我们采用了业界领先的微服务架构：
>
> - **前端**：基于 Vue 3 + Vite，配合 ECharts 可视化，打造流畅的用户体验
> - **后端**：Spring Boot 3.2 + Spring AI，集成通义千问大模型
> - **数据存储**：MySQL 8.0 + Redis 缓存，确保高性能数据访问
> - **部署方式**：Docker 容器化，支持一键部署和弹性扩展
>
> **核心功能**包括：
>
> 1. **实时天气监测** - 覆盖全国 2000+ 城市，分钟级数据更新
> 2. **AI 智能分析** - 基于大语言模型的多维度天气解读
> 3. **生活指数建议** - 穿衣、运动、洗车等 10+ 种生活建议
> 4. **可视化数据大屏** - 温度、湿度、空气质量的动态展示
> 5. **多模态交互** - 支持文字、图片的智能问答

## 【技术亮点】3:30 - 4:30（60 秒）

### 画面：技术架构图 + 代码片段

**演讲词**：

> SkyGazeer 的技术实现有三大亮点：
>
> **第一，AI 深度集成**
>
> 我们基于 Spring AI 框架，集成了通义千问大模型，并针对天气领域进行了专业优化。
>
> 通过 RAG 检索增强生成技术，AI 可以准确理解气象术语，给出专业建议。
>
> **第二，高性能架构**
>
> - Redis 缓存层，热点数据响应时间 < 50ms
> - 数据库读写分离，支持高并发查询
> - Docker 容器化部署，支持水平扩展
>
> **第三，企业级安全**
>
> - JWT + Spring Security 双重认证
> - API 限流防护，防止恶意请求
> - 数据加密传输，保障用户隐私
>
> 整个系统代码规范，遵循 SOLID 原则，易于维护和扩展。
